🎓 Projeto Alura+
Recriação da página de vendas do Combo+ (Alura+ e Alura Língua), feita como projeto de estudo do curso de HTML5 e CSS3 da Alura. O foco é praticar layout, imagens, seções e responsividade com HTML e CSS puros.
🔗 Online: projetoaluraplus-smoky.vercel.app
⚠️ Projeto educacional, sem fins comerciais. Alura, Alura+ e Alura Língua são marcas de seus respectivos donos.
✨ O que tem na página
Banner principal com a oferta do Combo+ e botões de assinatura
"Assista do seu jeito": mostra a plataforma em TV, tablet, notebook e celular
"Baixe seus cursos": destaque para assistir offline
Dispositivos disponíveis: TV, computador e celular, com ícones
Rodapé com links institucionais e informações legais
🛠️ Tecnologias
HTML5
CSS3
Deploy na Vercel
▶️ Como rodar localmente
git clone https://github.com/rafaelmagnon/projetoaluraplus.git
cd projetoaluraplus
Depois é só abrir o index.html no navegador. Não precisa instalar nada.

Estrutura semântica com HTML5

Uso de imagens de fundo e ilustrativas
